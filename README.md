# Sales-Revenue-Analysis-Dashboard
This project is an interactive **Sales & Revenue Analysis Dashboard** built using Microsoft Excel to analyze business KPIs, track financial data, and visualize revenue trends.

* **Thiranex Portal:** [Thiranex Dashboard](https://thiranex.in)

* **KPI Tracking:** Monitored Total Sales (₹606,000) and Total Profits (₹141,000) using custom summary cards.
* **Category Analysis:** Analyzed sales across Electronics, Clothing, and Footwear categories.
* **Product Performance:** Tracked top-performing items like Laptops and Smartphones.
* **Regional Insights:** Analyzed business growth across East, West, North, and South areas.
* Microsoft Excel (Advanced Formulas, Data Visualizations, Layout Design)
